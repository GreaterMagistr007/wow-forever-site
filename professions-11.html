Сбор

  • GatherMate2 запоминает точки сбора на карте и миникарте. Версия Forever: 1.52.4 от 3.11 (TOC 16001), по другому сайту 1.52.5 от 6.11, по третьему — альфа от 22.10 спорно (источник, источник, источник)
  • Баг GatherMate2 (баг-репорт 06.11.2026, с бета-клиента): в стартовых «микро-зонах» точки не показываются и не записываются; выход в родительскую зону восстанавливает Forever (источник)
  • Если точки не видны на миникарте — проверить, включён ли поиск трав/минералов у персонажа; база точек в Forever заполняется с нуля (зоны изменены) без источника

Планировщики прокачки (CurseForge)

Большинство обновлены в ноябре 2026, многие новые и малоскачиваемые — смотреть комментарии.

Аддон Что делает Метка
Profession Planner (GrovahGaming, ~102.5K загрузок — самый популярный) самый дешёвый маршрут до 75/150/225/300, цены из Auctionator или TSM Forever (источник)
Forever Professions (DarkDracos89) то же, использует данные Blackthornes Farmer при наличии Forever (источник)
Profs! (ETMA) маршруты Cheapest / Fastest / Balanced, списки покупок, ведомый крафт; использует TSM, Auctionator, Pawn, GatherMate2; заявлен Forever 1.60.x (16001), «ещё мало тестирован на живом сервере» Forever (источник)
Forever Profession Capper (Cyrieusgaming) одна рекомендация «что крафтить следующим» по ценам Auctionator; Interface 16001 Forever (источник)
Professionator-Forever (Dizzy_Frostgaard) шаги 1–300, библиотека рецептов, окно сбора Forever (источник)

  • Ставить один планировщик (Profession Planner как самый проверенный или Profs!) в паре с Auctionator без источника

Цены и альты

  • Auctionator для Forever есть: сборки 341 (13.10) / 343 (8.11) по одним данным, 341 (13.10) / 344 (09.11) — по другим; лежит на Wago. Многие планировщики берут цены из него спорно (источник)
  • Историю цен Auctionator собирает только из собственных сканов, а экономика Forever стартовала 04.11 с нуля — сканировать при каждом визите Forever (источник)
  • TradeSkillMaster: по одним данным версия для Forever появилась (v4.15.5, 9.11; в октябре её не было), по другим — версий TSM для Forever нет спорно (источник, источник)
  • Altoholic (рецепты и сумки всех альтов): файл для Forever есть (v1.60.005 от 14.10) Forever (источник)
  • Baganator (нужен Syndicator) — поиск предметов по всем персонажам и банкам, удобно, если ремесленник — альт Forever (источник)
  • LootAppraiser Reloaded — есть для Forever; Postal и оригинальный LootAppraiser — нет (на 9.11); вместо Postal — неофициальный порт Posty (GitHub, на свой риск) Forever (источник)
  • Почта между персонажами одного аккаунта мгновенная; аккаунтового банка нет — реагенты альту-крафтеру передаются почтой Forever (источник)
