Макросы

  • Mouseover-макросы работают: /cast [@mouseover,help,nodead][] Flash Heal лечит того, кто под курсором, иначе текущую цель; для врага — [@mouseover,harm,nodead][]. Forever (wow-forever.gg, RankedBoost)
  • Проверено в игре 20.11.2026 по журналу боя аддона ClaudeSync (клиент 1.60.1.70959). Forever
  • /castsequence работает, reset=target сбрасывает последовательность при смене цели. Шаг засчитывается только при успешном касте; /castsequence — единственный надёжный способ «ротации на одной кнопке».
  • Приоритет «первое доступное» строками /cast А / /cast Б не работает: если А сорвался (перезарядка), заклинания с глобальной перезарядкой из следующих строк в этом нажатии даже не пробуются; проходит только !Выстрел (жезл).
  • Каждая попытка каста, даже неудачная, выключает стрельбу жезлом. Строка /cast !Выстрел в том же макросе тут же включает её снова, глобальная перезарядка от этого не пускает следующие заклинания — жезл «то стреляет, то опускает руки». Жезл в макросе с заклинаниями — только по модификатору: /cast [mod] !Выстрел и /stopmacro [mod].
  • Предел макроса — 255 символов, а не байт: русский макрос на 218 символов (326 байт) сохраняется целиком.
  • Приём /castsequence Заклинание, null (один раз на цель) работает, но пока последовательность стоит на null, значок макроса с #showtooltip — вопросик.
  • Сброс по времени reset=N считает секунды от последнего нажатия, дошедшего до строки (в том числе на шаге null), а не от последнего каста. При частых нажатиях (разрыв меньше N) сброс не наступает: /castsequence reset=9 Взрыв разума, null дал Взрыв один раз за бой — после него 13 с только Пытки (журнал боя 24.11.2026). Отслеживать перезарядку таймером нельзя; срабатывает reset=N только в паузе между боями. reset=target работает.
  • /stopmacro [channeling] не спасает от срабатывания макроса в первые 10–30 мс после начала канала: клиент ещё не отметил канал, повторное срабатывание пробует следующий шаг, и канал не начинается. Жать ритмично, не зажимать клавишу. (вывод по журналу)
  • Аддону запрещено подписываться на журнал боя (COMBAT_LOG_EVENT_UNFILTERED) — клиент блокирует аддон окном «доступно только интерфейсу Blizzard»; мана игрока в бою для аддонов скрыта.
  • Простые макросы с синтаксисом Classic Era, для Forever отдельно не подтверждены: автоатака вместе с умением — #showtooltip / /startattack / /cast Heroic Strike; поиск редкого моба или квестового NPC — /tar <имя>; каст на себя без смены цели — /cast [@player] <заклинание>; прервать каст и сразу применить другое — /stopcasting первой строкой. Classic без источника
  • Найти цель по имени и поставить на неё красный крест (Raid Target, метка цели №7): /cleartarget /targetexact <имя> /run if UnitExists("target") and GetRaidTargetIndex("target")~=7 then SetRaidTarget("target",7) end /cleartarget нужен, чтобы при неудачном поиске крест не получила прежняя цель. /targetexact ищет точное имя, /target — часть имени (может взять не того). Проверка ~=7 не даёт повторному нажатию снять метку. Короткий вариант без скрипта — /tm 7 третьей строкой, но повторное нажатие может снять крест. Номера меток: 1 звезда, 2 круг, 3 ромб, 4 треугольник, 5 луна, 6 квадрат, 7 крест, 8 череп. Имя — как в клиенте (в русском клиенте русское); цель ищется только в пределах видимости; в рейде метки ставят лидер и помощники; первый /run клиент может попросить разрешить. В игре не проверено (18.11.2026). Classic без источника
  • Ботоподобные макросы и «один клик — вся ротация» через сторонние программы запрещены, риск бана; один макрос — одно действие на одно нажатие. без источника
