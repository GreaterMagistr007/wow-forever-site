Гайд-аддоны маршрутов под Forever

Установка аддонов и Questie — в категории «Аддоны». Здесь — что умеют пошаговые маршрутизаторы.

Аддон Что есть для Forever Цена Статус
RestedXP Маршруты Forever 1–35 для обеих фракций (+125 новых квестов: 62 Альянс, 63 Орда); после 35 — маршруты Classic Era без квестов Forever; отдельные маршруты Zephras Isle (Остров Зефрис) Бесплатно 1–20; полный гайд $45 (обе фракции) / $30 (одна) Forever (Kami Labs)
4Ever Leveling Пошаговые маршруты 1–60 для обеих фракций, команда /4ever, обновляется под Forever Бесплатно Не проверен Forever (CurseForge)
Polestar Guides Open-source гайд-аддон, маршруты для каждого старта, «найдены симуляцией»; совместим с Shortest Path Forever Бесплатно Не проверен Forever (CurseForge)
Guidelime Версии для Forever нет: проект пишет «только WoW Classic» — Classic (GitHub)

RestedXP подробнее

  • Данные на 09.10.2026. Forever-маршруты 35–60 обещаны без даты; в планах Dungeon Leveling Guide и Legacy Guide. После Zephras Isle (Остров Зефрис) маршрут ведёт Альянс в Westfall (Западный Край), Орду — в Silverpine (Серебряный бор) или The Barrens (Степи). Статья Kami Labs содержит партнёрские ссылки. Forever (Kami Labs)
  • Linux: по пересказу Kami Labs, RestedXP официально поддерживает только Windows и Mac; на Linux, Wine, Proton и Steam Deck теряется право на возврат денег. Платную часть покупать только с пониманием этого риска; бесплатные 1–20 можно проверить. Forever (Kami Labs)
  • Для группы есть RXP Party Sync Forever — синхронизация шагов гайда. Forever (CurseForge)

Прочее

  • Gfinity называет бесплатной альтернативой OpenXP, но Gfinity уже пойман на выдуманных деталях по Forever — без проверки не доверять. (Gfinity)
  • Joana: версии для Forever нет. без источника
  • С Questie гайд-аддоны обычно уживаются, но метки дублируются (вывод, не факт из источника). без источника
